# Day 002 - Weather CLI App

Aplikasi terminal sederhana untuk mengambil dan menampilkan data cuaca real-time berdasarkan koordinat kota menggunakan **Open-Meteo API**.

## Fitur

- Mengambil data suhu, kelembapan, dan kecepatan angin secara _real-time_.
- Tanpa memerlukan API Key.
- Tampilan output terminal yang bersih dan terformat.

## Persyaratan

Install library `requests`:

```bash
pip install requests
```
