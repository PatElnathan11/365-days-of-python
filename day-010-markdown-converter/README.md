# Day 010 - Markdown to HTML Converter CLI

Script Python buatan sendiri untuk merender file Markdown (`.md`) menjadi halaman dokumen HTML interaktif lengkap dengan tampilan CSS modern.

## Fitur

- Parsing sintaks Markdown (Header, Bold, Italic, Code, Link, & List).
- Templating HTML otomatis dengan gaya CSS terintegrasi.
- Mengonversi file tunggal atau seluruh file `.md` di folder secara otomatis.

## Cara Penggunaan

Jalankan script dari terminal:

```bash
python main.py
```
