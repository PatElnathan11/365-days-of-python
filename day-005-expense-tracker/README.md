# Day 005 - Expense Tracker CLI

Aplikasi terminal sederhana untuk mencatat dan mengelola pengeluaran harian pribadi yang tersimpan dalam format JSON.

## Fitur

- Menambah catatan pengeluaran baru (deskripsi, nominal, & kategori).
- Menampilkan seluruh riwayat pengeluaran beserta total pengeluaran secara terformat.
- Penyimpanan data permanen (_persistent storage_) menggunakan file `expenses.json`.

## Cara Penggunaan

Jalankan script dari terminal:

```bash
python main.py
```
