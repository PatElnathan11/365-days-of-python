# Day 001 - PDF Merger Script

Script Python sederhana untuk menggabungkan beberapa file PDF yang berada di dalam satu folder menjadi satu file PDF utuh.

## Fitur

- Mengurutkan file PDF berdasarkan nama file secara otomatis.
- Menggabungkan seluruh file `.pdf` di folder target menjadi `merged_result.pdf`.

## Persyaratan

Install library `pypdf` terlebih dahulu:

```bash
pip install pypdf
```

## Cara penggunaan

- Masukkan file-file PDF yang ingin digabung ke dalam folder day-001-pdf-merger.
- Jalankan script:
  python main.py
- Hasil gabungan akan muncul dengan nama merged_result.pdf.
