# Day 012 - Bulk File Renamer CLI

Script Python untuk mengubah nama file secara massal dengan berbagai opsi penamaan dan fitur _Dry Run_ agar perubahan nama aman terprediksi.

## Fitur

- **Dry Run Mode:** Preview hasil rename sebelum benar-benar mengubah file di disk.
- **Prefix & Suffix:** Menambahkan teks di depan atau belakang nama file.
- **Sequential Numbering:** Memberi nomor urut otomatis (misal: `photo_001.jpg`, `photo_002.jpg`).
- **Find & Replace:** Mengganti kata tertentu pada nama file.
- **Date Stamping:** Menambahkan tanggal modifikasi file ke dalam nama file.

## Cara Penggunaan

Jalankan script dari terminal:

```bash
python main.py
```
