# Day 003 - Automatic Folder Organizer

Script Python otomatis untuk memilah dan merapikan file-file di dalam folder target berdasarkan tipe/ekstensi filenya.

## Fitur

- Pengelompokan otomatis ke folder: `Images`, `Documents`, `Videos`, `Audio`, `Archives`, `Scripts`, dan `Others`.
- Penanganan konflik jika file dengan nama sama sudah ada di folder tujuan.
- Memanfaatkan library standar Python tanpa dependensi eksternal.

## Cara Penggunaan

1. Jalankan script dari terminal:
   ```bash
   python main.py
   ```
