# Day 004 - Random Password Generator & Strength Checker

Aplikasi CLI sederhana untuk membuat password acak yang aman secara kriptografis dan mengecek tingkat kekuatan password.

## Fitur

- Penjumlahan & kustomisasi kombinasi password (panjang, huruf kapital, angka, & simbol).
- Menggunakan modul `secrets` untuk keamanan acak tingkat kriptografi.
- Modul _Password Strength Checker_ menggunakan ekspresi reguler (Regex).

## Cara Penggunaan

Jalankan script dari terminal:

```bash
python main.py
```
