# Day 006 - Log File Analyzer

Script Python untuk membaca, memproses, dan memvisualisasikan statistik sederhana dari file server log.

## Fitur

- Menghitung statistik tingkat keparahan log (`INFO`, `WARNING`, `ERROR`, `CRITICAL`).
- Menghitung distribusi status kode HTTP (misal: 200 OK, 404 Not Found, 500 Server Error).
- Mengidentifikasi Alamat IP teratas yang melakukan request terbanyak.
- Tidak memerlukan library pihak ketiga (pure Python standard library).

## Cara Penggunaan

Jalankan script dari terminal:

```bash
python main.py
```
