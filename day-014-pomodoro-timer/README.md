# Day 014 - Pomodoro Timer & Focus Logger CLI

Aplikasi timer produktivitas berbasis terminal menggunakan metode Pomodoro lengkap dengan pencatatan riwayat sesi fokus otomatis.

## Fitur
- **Live Countdown Display:** Hitung mundur waktu secara *real-time* di satu baris terminal tanpa memenuhi layar.
- **Preset & Custom Timer:** Pilihan sesi standar (25 menit), sesi singkat (15 menit), atau mode tes cepat (10 detik).
- **Focus Session Logger:** Menyimpan setiap sesi yang berhasil diselesaikan ke `focus_log.json`.
- **Statistik Fokus:** Menampilkan total waktu fokus dan daftar tugas yang telah dikerjakan.

## Cara Penggunaan
Jalankan script dari terminal:
```bash
python main.py
