# Day 020 - Git Repository Activity & Commit Analyzer CLI

Utilitas berbasis terminal untuk menganalisis riwayat commit, produktivitas kontributor, dan pola aktivitas dari repository Git lokal.

## Fitur

- **Commit & Author Analytics:** Menghitung total commit serta kontribusi tiap developer beserta persentasenya.
- **Day-of-Week Breakdown:** Menampilkan distribusi aktivitas commit berdasarkan hari dalam seminggu dengan grafik batang ASCII.
- **Recent Activity Feed:** Menampilkan daftar 5 commit terakhir beserta hash singkat, tanggal, dan pesan commit.
- **JSON Report Export:** Menyimpan ringkasan statistik repository ke dalam file `git_report.json`.

## Cara Penggunaan

Jalankan script dari terminal:

```bash
python main.py
```
